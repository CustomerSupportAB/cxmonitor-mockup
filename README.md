# CXMonitor Mockup

Interactive demo of a customer support analytics dashboard for Acentecom.

## What this is
A clickable mockup showing what CXMonitor would look like once connected
to the customer-support-database Supabase via read-only credentials.

## To view
Open `cxmonitor_demo_1.html` in any browser, or view the hosted version at:
https://customersupportab.github.io/cxmonitor-mockup/cxmonitor_demo_1.html

## Tech
- Single self-contained HTML file
- Synthetic data structured against the live schema
- No real customer data, no live API calls
